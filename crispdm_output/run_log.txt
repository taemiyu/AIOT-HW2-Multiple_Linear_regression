
======================================================================
PHASE 1: BUSINESS UNDERSTANDING
======================================================================
objective: Help a venture capital fund estimate a startup's annual profit from its spending profile and location.
business_questions: ['Which spending category (R&D, Administration, Marketing) drives profit most?', 'Does the state where the startup operates affect profit?', 'How accurately can profit be predicted for a new startup?']
data_mining_goal: Build a multiple linear regression model Profit = f(R&D, Admin, Marketing, State).
success_criteria: {'test_R2_min': 0.9, 'cv_R2_min': 0.85, 'MAPE_max_pct': 10.0}

--- 1.2 Situation assessment ---
resources: One public CSV (50 rows), Python + scikit-learn.
assumptions: Spend figures are annual and comparable across startups.
constraints: Tiny sample -> no deep models; must stay interpretable.
risks: ['Small sample -> unstable estimates (mitigate: cross-validation).', 'Zero spend values may be missing data rather than true zeros.']
cost_benefit: Cheap to build; wrong predictions cost the fund money, so the model supports, not replaces, analyst judgment.

--- 1.4 Project plan ---
 - Phase 2: profile data, correlations, quality checks
 - Phase 3: clean, encode State, split train/test
 - Phase 4: OLS on every feature subset, choose by CV R2
 - Phase 5: test-set metrics vs success criteria, decide go/no-go
 - Phase 6: deploy only if approved; write final report
